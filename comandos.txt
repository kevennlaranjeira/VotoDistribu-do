Adicionar host local:
127.0.0.1 coletor.local

Preparar ambiente:
cp .env.example .env

Validar compose:
docker compose config

Subir stack com 3 replicas do coletor:
docker compose up -d --build --scale coletor=3

Ver containers:
docker compose ps

Parar stack:
docker compose down

Parar e limpar volumes:
docker compose down -v
